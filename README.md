# Digital Ecosystem Lab

A browser-based procedural ecosystem simulation built with plain HTML, CSS, and modular JavaScript.

## Features
- Herbivore and predator AI
- Energy, aging, reproduction, mutation, and inherited genes
- Adjustable food growth, mutation strength, speed, and friction
- Click-to-inspect creature stats
- Canvas-rendered population history
- LocalStorage save/load
- JSON import/export
- Responsive light/dark interface
- No external libraries

## Run
Because it uses ES modules, start a local server in this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
